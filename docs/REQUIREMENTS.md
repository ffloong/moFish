# MoFish Browser — 需求文档

## 1. 产品定位

MoFish Browser 是一个基于 Electron 的**多窗口网页管理桌面应用**。每个网页页面以独立窗口形态存在，用户可以单独控制每个页面的大小、透明度、置顶状态、显示/隐藏、聚焦切换。

核心价值：将浏览器中的多个页面从"同一窗口的 Tab"升级为"独立可控的系统级窗口"，满足悬浮查看、并排对照、快速隐藏、多页面工作流等场景。

---

## 2. 目标用户

- 需要同时监控多个网页（如数据看板、聊天工具、文档）的用户
- 希望将某些网页以透明悬浮方式置顶显示的用户
- 需要快速隐藏/恢复私密页面或工作页面的用户
- 需要在多个网页间快速切换和布局的用户

---

## 3. 核心术语

| 术语 | 定义 |
|------|------|
| Page Window | 一个加载了网页内容的独立 BrowserWindow |
| Page Manager | 应用主窗口，用于列出和管理所有 Page Window |
| Page State | 某个 Page Window 的完整状态：URL、标题、位置、大小、透明度、置顶、可见性 |
| Workspace | 一组 Page Window 的布局和状态快照，可保存/恢复 |

## 4. 功能需求

### 4.1 页面管理器（主窗口）

#### FR-PM-01：新建页面

- 用户可以在页面管理器中输入 URL 并创建新页面
- 新页面以独立窗口打开
- 自动识别并补全 URL（如输入 `example.com` 自动补全为 `https://example.com`）
- 支持打开本地 HTML 文件

#### FR-PM-02：页面列表

- 页面管理器中实时显示所有已创建的页面
- 每个列表项包含：
  - 页面标题
  - 页面 URL（缩略显示）
  - 当前状态徽标（置顶/透明/隐藏）
  - 页面缩略图（可选，Phase 2）
- 列表按创建时间或最近使用时间排序

#### FR-PM-03：页面搜索

- 用户可以通过标题或 URL 关键词搜索页面
- 搜索结果实时过滤

#### FR-PM-04：关闭页面

- 用户可以关闭单个页面
- 关闭前如有表单数据，弹出确认提示
- 关闭后从列表中移除

#### FR-PM-05：批量操作

- 全部显示
- 全部隐藏
- 全部关闭（需确认）
- 关闭其他页面（需确认）

---

### 4.2 单页面窗口控制

#### FR-WC-01：窗口大小控制

- 用户可以拖拽窗口边缘调整大小
- 用户可以通过页面管理器或快捷菜单精确设置宽高
- 支持预设尺寸：`640×480`、`800×600`、`1024×768`、`1280×800`、自定义
- 记住用户上次使用的尺寸

#### FR-WC-02：窗口透明度控制

- 透明度范围：`0.1` — `1.0`
- 步进值：`0.05`
- 用户可通过滑块或快捷键调节
- 透明度低于 `0.3` 时显示警告提示
- 每个页面独立记忆透明度

#### FR-WC-03：窗口置顶控制

- 用户可以切换置顶开关
- 置顶模式支持优先级：`floating`（悬浮）、`screen-saver`（最高级）
- 置顶窗口在标题栏或边框显示视觉指示
- 每个页面独立记忆置顶状态

#### FR-WC-04：窗口位置控制

- 用户可以拖拽窗口移动位置
- 用户可以通过管理器精确设置 X/Y 坐标
- 支持快捷布局：
  - 左半屏
  - 右半屏
  - 上半屏
  - 下半屏
  - 居中
  - 全屏

#### FR-WC-05：窗口隐藏/显示

- 用户可以隐藏单个页面窗口（从屏幕移除但保持运行）
- 用户可以从管理器恢复显示隐藏的页面
- 隐藏的页面继续加载和运行，不中断
- 隐藏状态在管理器列表中有明确视觉区分

#### FR-WC-06：窗口聚焦切换

- 用户可以通过管理器点击某个页面使其获得焦点
- 支持快捷键 `Ctrl/Cmd + 数字` 快速切换到对应页面
- 支持在所有页面间循环切换（`Ctrl/Cmd + Tab`）

---

### 4.3 页面窗口外观

#### FR-WA-01：窗口模式

- **有边框模式**：显示系统标题栏，包含最小化/最大化/关闭按钮
- **无边框模式**：不显示系统标题栏，由应用自绘控制条
- **迷你模式**：仅保留网页内容和一个极窄控制条

#### FR-WA-02：窗口标题

- 默认显示网页标题
- 用户可自定义重命名
- 支持显示 favicon 图标

#### FR-WA-03：右键菜单

页面窗口内右键提供快捷操作：
- 复制页面 URL
- 刷新
- 前进/后退
- 调整透明度（子菜单：25% / 50% / 75% / 100%）
- 切换置顶
- 隐藏此窗口
- 关闭此窗口

---

### 4.4 快捷键系统

#### FR-HK-01：全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl + N` | 新建页面 |
| `Cmd/Ctrl + W` | 关闭当前页面 |
| `Cmd/Ctrl + H` | 隐藏/显示当前页面 |
| `Cmd/Ctrl + 1~9` | 切换到第 N 个页面 |
| `Cmd/Ctrl + Tab` | 循环切换页面 |
| `Cmd/Ctrl + +` | 透明度增加 |
| `Cmd/Ctrl + -` | 透明度减少 |
| `Cmd/Ctrl + T` | 切换置顶 |

#### FR-HK-02：自定义快捷键

- 用户可在设置中修改快捷键绑定
- 支持冲突检测

---

### 4.5 状态持久化

#### FR-PS-01：页面状态保存

应用退出时自动保存所有页面状态：

```ts
interface PersistedPageState {
  id: string;
  url: string;
  title: string;
  bounds: { x: number; y: number; width: number; height: number };
  opacity: number;
  alwaysOnTop: boolean;
  visible: boolean;
  createdAt: number;
  lastActiveAt: number;
}
```

#### FR-PS-02：启动恢复

- 应用启动时恢复上次会话的所有页面
- 用户可选择：恢复所有 / 只恢复管理器 / 从空白开始

#### FR-PS-03：Workspace 管理

- 用户可以保存当前布局为 Workspace
- 用户可以加载已保存的 Workspace
- Workspace 包含所有页面的完整状态
- 支持命名、重命名、删除 Workspace

---

### 4.6 设置

#### FR-ST-01：通用设置

- 默认窗口大小
- 默认透明度
- 默认置顶状态
- 默认窗口模式（有边框/无边框）
- 启动行为（恢复上次会话 / 空白启动）

#### FR-ST-02：外观设置

- 管理器主题（浅色/深色/跟随系统）
- 管理器界面语言（中文/英文）
- 页面列表显示密度（紧凑/舒适）

#### FR-ST-03：快捷键设置

- 查看所有快捷键
- 自定义修改快捷键
- 重置默认快捷键

## 5. 非功能需求

### NFR-01：性能

- 页面管理器渲染响应时间 ≤ 100ms
- 新建页面到窗口显示 ≤ 500ms
- 透明度调节实时响应，无肉眼可见延迟
- 支持同时运行 ≥ 20 个页面窗口
- 应用空闲内存占用 ≤ 200MB（不含页面内容）

### NFR-02：安全

- 所有页面运行在 `contextIsolation: true` 环境下
- 禁用 `nodeIntegration`
- 使用 `preload` 脚本安全暴露 IPC 接口
- URL 输入进行协议白名单校验（仅允许 `http://`、`https://`、`file://`）

### NFR-03：兼容性

- macOS 12+
- Windows 10/11
- 主流 Linux 发行版（Ubuntu 20.04+）

### NFR-04：可用性

- 所有核心操作 ≤ 2 次点击可达
- 快捷键操作 ≤ 1 次组合键
- 首次启动提供简短引导

### NFR-05：数据完整性

- 应用异常退出不丢失页面列表
- 状态保存采用原子写入
- 支持 JSON 格式导出/导入配置

## 6. 技术约束

| 约束项 | 选择 | 理由 |
|--------|------|------|
| 框架 | Electron ≥ 30 | 成熟的多窗口 API，跨平台 |
| 前端 | React 18 + TypeScript | 组件化管理器 UI |
| 构建 | Vite + electron-builder | 开发体验与打包 |
| 状态管理 | Zustand | 轻量，适合 IPC 同步 |
| IPC | Electron `ipcMain` / `ipcRenderer` + `preload` | 安全的进程通信 |
| 样式 | Tailwind CSS | 快速 UI 开发 |
| 代码质量 | ESLint + Prettier + TypeScript strict | 保证可维护性 |
| 测试 | Vitest + Playwright | 单元测试 + E2E |

## 7. 用户流程

### 7.1 首次使用流程

```text
启动 App
  → 显示页面管理器
  → 首次引导提示（简短说明）
  → 用户输入 URL 创建第一个页面
  → 页面以独立窗口打开
  → 用户在管理器或窗口中调整大小/透明度/置顶等
```

### 7.2 日常使用流程

```text
打开 App
  → 自动恢复上次会话页面
  → 用户通过管理器/快捷键操作页面
  → 关闭 App 时保存状态
```

### 7.3 悬浮查看流程

```text
选择某页面
  → 设为无边框模式
  → 调整透明度至 0.8
  → 开启置顶
  → 拖拽至目标位置
  → 完成悬浮查看
```

### 7.4 快速隐藏流程

```text
正在浏览私密页面
  → 按下 Cmd/Ctrl + H
  → 当前页面立即隐藏
  → 管理器中显示"已隐藏"状态
  → 需要时从管理器恢复显示
```
